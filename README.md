# time-portals
A web app to create "portals" showing a historical view of landmarks


## Summary

A fork of [CMorenoStokoe/time-portals](https://github.com/CMorenoStokoe/time-portals). A web app for creating "portals" that show historical views of landmarks.

## What's inside

`app/` (the front end), `backend/`, `database/`, `agents/` and `AGENTS.md`, plus `package.json`.

## How to view or run it

Follow the scripts in `package.json` (typically `npm install`, then `npm run dev`). The upstream live version is at https://time-portals.vercel.app.
